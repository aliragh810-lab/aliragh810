# BrowserTrace

## شعار الأداة

**BrowserTrace — التتبع الجنائي الرقمي لمتصفحات الويب**

## 

## الوصف

BrowserTrace أداة جنائية رقمية مبنية بلغة Python القياسية لاستخراج وتحليل آثار المتصفحات بطريقة غير تعديلية. تدعم عشرين متصفحًا عبر تصميم قائم على عائلات Chromium وFirefox وWebKit.

## المميزات

- اكتشاف المتصفحات والملفات الشخصية تلقائيًا على Windows وLinux.
- استخراج السجل والتنزيلات وملفات الارتباط والإشارات المرجعية وبيانات الملء التلقائي وبيانات تسجيل الدخول وعبارات البحث والإضافات والإعدادات.
- حفظ كتل كلمات المرور المشفرة فقط دون فك التشفير.
- تقارير JSON وCSV وHTML.
- مرشحات زمنية ونطاق وكلمة مفتاحية ونوع ملف.
- خيار `--limit` للسيطرة على عدد النتائج المعروضة.
- واجهة تفاعلية ملونة وسجل أوامر.
- لا يوجد اتصال شبكي ولا تعديل لملفات المتصفح الأصلية.

## المتطلبات

Python 3.8 أو أحدث على Windows أو Linux. لا توجد مكتبات خارجية.

## التثبيت

بعد فك الحزمة التنفيذية يمكن تشغيل:

`python browsertrace.pyz --version`

ثم:

`python browsertrace.pyz install`

## أمثلة

`python -m browsertrace scan`

`python -m browsertrace history --browser chrome --limit 20`

`python -m browsertrace downloads --limit 10 --format json --output report.json`

`python -m browsertrace report --browser chrome --format html --output report.html`

## خيار --limit

القيمة الافتراضية 50. القيمة 0 تعني عرض جميع النتائج، مع تحذير عند تجاوز 1000 نتيجة.

## الاعتبارات القانونية والأخلاقية

يجب استخدام BrowserTrace فقط على أجهزة وملفات لديك تصريح قانوني بفحصها. بيانات الاعتماد المشفرة تعامل كأدلة حساسة، ولا تقوم الأداة بفك تشفيرها.
